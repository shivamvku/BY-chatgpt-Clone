# Historical Documentation Archive

This directory contains historical documentation that has been superseded by newer versions but is preserved for reference and context.

## Archive Organization

- **Date-based folders**: Documents archived by the date they were superseded (YYYY-MM-DD format)
- **Original paths preserved**: Maintain original directory structure within archive folders
- **Change documentation**: Each archived item includes context about why it was superseded

## Currently Active Documentation

All current documentation is maintained in the main docs/ directory. See:
- **[Main Documentation](../README.md)** for the current documentation index
- **[Azure Architecture Diagrams](../diagrams/README.md)** for current technical diagrams
- **[Implementation Plan](../implementation-plan.md)** for current project scope and status

## Archive Policy

Documents are archived when:
- Technical architecture changes make diagrams obsolete
- Process improvements supersede operational documentation
- Consolidation efforts merge multiple documents into unified versions

Archived documents remain accessible for:
- Historical reference and context
- Understanding evolution of system design
- Compliance and audit requirements
